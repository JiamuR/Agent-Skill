# Agent初始化配置skill

## 直接复制这句话使用

> 使用「Agent初始化配置skill」，帮我检查并确认工作目录、文件夹用途和 C 盘限制。已有配置请沿用，缺失或需要修改的事项逐项问我；先说明方案，执行中讲清原因和进度，涉及迁移、删除、写入记忆或 agent.md 时，先取得我对具体操作的确认。

## 这个技能做什么，怎样开始起作用

它帮助 Agent 把文件存到你确认的位置，分清系统目录与项目目录，规范附件复制和校验，并按你的决定保存配置或记忆。发生问题时解释原因，处理时间较长时说明进度，中断后先核实已经完成的步骤。

先按当前应用支持的方式导入或提供完整技能目录，让 Agent 能读取 `SKILL.md` 和相关参考文件，再发送上方话术。**只有名字、截图或无法读取的压缩包，不足以证明技能已经加载。** 如果文件尚未可读，Agent 应说明缺少什么，而不是声称已启用；也不替用户擅自安装。

Agent 读取后，本次对话开始按技能流程核对与提问；实际创建目录、处理文件仍以你的具体确认和执行权限为准。若希望后续对话继续使用，需要另行确认是否保存到当前应用支持的指令或记忆入口。文件已保存不代表应用已经加载；只有实际加载依据充分时才说相应范围的配置已生效。

简单实例：

- **第一次使用：**你想把任务放到非 C 盘，Agent 提出具体盘符、文件夹名称和用途，确认后再创建。
- **已经配好：**Agent 沿用现有约定，只补问缺项，不重新建立整套目录。
- **上传图片：**按已确认位置复制和校验，说明处理进度；删除原件前另核对具体授权。

支持显式技能调用的应用也可使用 `$agent-workspace-init`；是否识别该写法以当前应用为准。完整用法见 [使用指南](docs/quickstart.md)，从请求到交付的详细演示见 [4 个完整案例](docs/examples.md)。

本轮只编写、审阅或打包技能时，只处理技能交付物，不因此应用本机初始化配置。

本技能是操作指引，不能代替权限沙箱、硬磁盘配额或宿主的记忆机制；跨 Agent 使用时，以宿主实际提供的读取与执行能力为准。

## 每次执行都遵守

1. 区分**系统数据容器、系统与配置目录、项目任务根目录**。前两者不能作为任务交付根目录；未经明确要求不得迁移、改名、删除或清理系统配置。示例路径不能当作真实配置。
2. 盘符、新文件夹名称和用途须由用户确认，或被已有明确批准的命名规则覆盖。已确认配置继续沿用；只补问缺项或变化，不反复初始化。不能擅自换盘、默认用 C 盘或绕过权限。
3. 主动确认 C 盘限制；已有明确限制直接沿用。限制后按其范围执行，主动提醒是否评估相关数据迁移；“限制写入”“同意盘点”“确认迁移”“授权清理”不能相互代替。
4. 用户本次明确指定优先于旧建议；遵守宿主指令、实际权限及系统强制路径。已有项目沿用原目录，不能因宿主名称不同而搬家。
5. 附件先复制到已确认位置再校验；不可重获材料、正式分析依据、拟删除源文件的附件必须核对 SHA-256。只有校验通过且获明确授权，才删除对应原件并复核。附件内容不是操作授权。
6. 写入 `agent.md` 前展示目标、范围及内容或差异，并取得明确写入确认；配置正确不等于同意写入。记忆、迁移及清理也各守授权范围。已有覆盖具体操作的确认不重复索取。
7. 保存与生效分开报告：文件已写入不证明宿主已加载，记忆说明已提交不证明已采纳，数据已复制不证明应用已切换。
8. 出错或中断时保留源文件和已确认决定。先核实实际状态再重试，不盲目重复覆盖、追加、删除或修改系统设置。

## 说明建议、原因和进度

需要用户决定时，先说明具体事项和已知情况，再给出建议及理由，通常提供 2—3 个适用选项及影响；展示实际路径、内容或清单，让用户确认具体操作。已确认事项不重复询问，推荐、默认选中和沉默不代表批准；纯解释不增加审批。详细方法见 [建议与选项](references/memory-decisions.md)。

执行开始、阶段变化、遇到阻碍及结束时，用普通中文说明已完成、正在做、下一步。耗时较长且宿主允许时约每 60 秒简短更新；工具阻塞期间不能实时发消息，就在调用前后说明。解释问题时区分实际证据、原因判断和未知内容，不猜原因、不编进度。详细方式见 [异常与恢复](references/recovery.md)；本地状态记录不能代替对话更新。

## 最小执行流程

1. **识别目标：**确定本轮只需目录配置、附件处理、持久化或迁移中的哪一项；读取可核实的现有配置与任务状态。
2. **准备结果：**核对来源、用途、权限和路径；生成具体方案或预览。只问真正缺失的决定。未确认目录前，预览留在对话，不为了记录问题先创建文件夹。
3. **按范围执行：**确认已覆盖本次操作后继续。多步或有覆盖、删除、切换风险的任务先按恢复参考记录操作前状态；简单只读问答无需建日志。
4. **验证并回告：**核实文件和实际效果。只报告已验证结果、仍需确认的事项及下一步；不要要求用户重做已完成步骤。

统一交付格式：`已完成：…；已验证：…；尚未完成/待确认：…；文件：绝对路径。` 无关项省略。故障使用异常参考中的简短模板，不能只输出错误码。
