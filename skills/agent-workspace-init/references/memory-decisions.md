# 记忆与用户决定

## 先区分记录用途

| 类型 | 可记录内容 | 保存边界 |
| --- | --- | --- |
| 任务记录 | 当前输入版本、进度、假设、用户决定、操作证据 | 按需保存到已确认工作目录，不等于长期记忆 |
| 长期记忆 | 稳定偏好、已确认项目规则、经过验证的可复用经验 | 用户明确要求记住、修订或删除，且宿主允许时处理 |
| 待确认内容 | 未确定偏好、功能设想、目录或授权选择 | 留在对话或项目清单，不冒充已确认规则 |

读取历史只检索与本轮相关的信息。路径、版本、权限和状态容易变化，使用前做必要核实；未核实时说明信息可能过时。最新用户要求优先于旧记忆，遵守宿主的引用规则。

## 长期记忆写入

用户明确说“记住这条”“更新/删除这条记忆”，指向具体内容和范围时按授权执行，不重复确认。只要求技能支持记忆、审阅规则、同意配置或完成本轮任务，不构成长期记忆写入授权。发现值得保留的内容可以提出简短候选，不强行给每个任务加记忆建议。

1. 明确新增、修订或删除、正文、项目/全局范围及用户依据。歧义只针对对应条目提问；一次目录例外不能扩展为全局偏好。
2. 使用宿主明确提供的工具或路径，不按 Agent 名称猜测入口。若宿主只允许提交更新说明，则创建 `<时间戳>-<主题>.md` 小文件，不直接编辑记忆主文件、摘要或历史。入口和实际权限是独立条件。
3. 只保存复用所需的最少信息及来源、时间，不保存密码、令牌、原始业务明细、完整对话或附件。修订/删除要定位旧条目并说明变化。
4. 已存在同一已提交更新时先核实结果，避免中断后重复追加。需要多步处理或结果未知时用 [恢复流程](recovery.md)。
5. 回读文件或检查工具结果；区分草稿、已提交、已采纳/生效。提交删除说明不等于原记忆已实际删除。没有采纳证据就不承诺未来会话必定加载。

宿主入口未知、不支持或无权限时，可在已确认工作目录保存草稿，明确尚未写入长期记忆；新增 `memory-drafts` 等文件夹须先确认名称与用途，未具备位置则在对话展示。权限不足通过宿主审批，不绕过；任务不依赖记忆的部分继续做。

更新说明字段：`操作、正文、范围、用户授权依据、含时区记录时间、旧条目定位（修订/删除时）`。未知字段不编造。

## 待用户确认事项

只跟踪真正需要用户决定的项目：新盘符/名称/用途、C 盘限制、系统目录保护、迁移方案、记忆持久化、指令文件写入，以及有实质影响的需求选择。常规实现细节自行处理，目录规则已覆盖的创建不反复询问。

简单问题在对话提出；需跨轮次时放已确认工作目录中的 `pending-decisions.md`。如果已有 `agent-init-state.md` 包含同一决定，优先维护同一份记录，不双写制造冲突。目录未确认时不为清单先创建目录。

每条用稳定编号，记录：具体事项、可行选项与建议、影响/依赖范围、决定状态、用户实际结论和可信依据、执行状态及证据。

- 决定状态：待确认 / 已确认 / 已否决 / 已撤回 / 已被替代。
- 执行状态：未执行 / 执行中 / 待验证 / 已验证 / 受阻或结果待核实。

提问时先完成已授权的准备，让用户审阅具体路径、内容或差异。必要信息缺失时尽早问，同时做独立工作。批准范围明确时一次确认可以覆盖多项，但不能把沉默、超时、默认选中或“先做其他工作”当批准。

低风险假设须标为假设；盘符、新目录用途、指令文件写入、迁移及删除等明确需要确认的事项不能按假设执行。新答复只覆盖其指向的事项；改变决定时保留依据，旧决定标为已替代。

确认方案与完成实施分开；决定记录本身不能自动写入长期记忆。恢复时核对可信依据，仅补问缺失或变化项；交付只列仍影响结果的待定项。

## 给用户建议与明确选项

需要用户决定时，用普通中文依次说明：具体需要决定的事项、目前已知情况、建议选项及其理由、可选方案各自的影响，以及哪些操作会在确认后执行。列出实际路径、内容或清单，不用“是否继续”代替具体问题。

通常给出 2—3 个适用且能区分的选项，推荐项标明理由；允许用户提出自己的方案。缺少足够事实时先核实或说明未知，不强行推荐。违反已确认限制、缺少必要校验或超出实际权限的操作，不能包装成可直接执行的选项；需要另行授权或审批时说明前提。可以暂停或只预览时，把该选择写清楚。

用户仅确认其中一项，只执行明确覆盖的范围。推荐项、默认选中、沉默和超时不等于批准。已有明确决定或授权不反复提问；纯解释性 FAQ 和常规可逆执行无需额外制造确认流程。

例如，指令文件写入前先展示具体路径、范围和差异，再给出：A. 确认写入这份内容；B. 修改指定内容后再确认；C. 只保留预览。用户选择 A 也不同时授权迁移数据或写入长期记忆。
